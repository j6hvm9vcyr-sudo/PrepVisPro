# Topshot — mémo pour Claude

App Mac (Tauri 2 + React 19 + TypeScript strict) de préparation pour chef opérateur : découpage, plans au sol, plans feux, soleil, jours de tournage. Utilisateur : Adrien Rousseau. Interface et messages en français.

## Règles
- Nom : **Topshot** (PrepVisPro jusqu'à la 0.11). Projets `Nom.topshot` ; un ancien `Nom.prepvis` est renommé à l'ouverture (`storage::rename_legacy`, jamais d'écrasement). Gardés exprès pour ne rien perdre : l'identifiant `fr.adrienrousseau.prepvispro` (dossier de données : préférences, icônes ; données WebKit : projets récents), les clés `prepvispro.*` du stockage local, `__prepvis`, les en-têtes `x-prepvis-*`, `prepvisVersion` des versions.
- **Fiabilité d'abord** : une fonction pas parfaitement fiable n'est pas intégrée. Aucune valeur inventée ; une valeur préréglée cite sa source et sa plage.
- Une seule source de vérité (`ProjectDoc`) ; rien n'est recopié d'une vue à l'autre.
- Icônes PF_ICONES : livrées avec l'app (`public/pf-icones` + `index.json`, libres de droits, décision d'Adrien 0.11.1) ; identifiants `pf/…`, jamais supprimables ; `DEFAULT_FIGURES` dans `platform/iconLibrary.ts`. Les tests d'import utilisent `e2e/icones-test`.
- Chaque build livré a un numéro : `node scripts/bump-version.mjs X.Y.Z`.
- Messages à Adrien : courts. Pas de nouvelle fonction sans demande.
- Décisions du projet : doc `claude/decisions-projet.md` du Project claude.ai (à tenir à jour).

## Règles d'interface (0.9, style 0.11)
- Une explication = un ⓘ (`Info`) à droite d'un titre ; jamais de phrase posée dans la page.
- Un seul code d'état (`StateDot`, `verify.ts`) ; un seul « À vérifier ».
- Raccourcis seulement dans les menus, les infobulles et la fiche « ? » (⌘/).
- Gauche : structure du film ; centre : le travail ; droite : la sélection, refermable. État vide = une ligne + un bouton.
- Thème clair uniquement (pas de mode sombre, décision d'Adrien). Police du Mac (SF Pro / SF Mono), IBM Plex en secours.
- Verre (imitation de Liquid Glass) seulement sur ce qui flotte : barres, colonnes latérales, palettes, bulles. Le contenu reste opaque.
- Un panneau en verre (`backdrop-filter`) devient le repère des éléments `position: fixed` : listes déroulantes (`Picker`), bulles ⓘ (`Info`) et aperçus passent par un portail.
- Pages et panneaux (0.18) : une page = une surface fixe ; tout le reste est un panneau qu'on ouvre ou ferme depuis la barre du haut. Pas de nouvelle vue à onglet.
- Refonte 0.24 (décision d'Adrien) : **une commande, une place** (+ raccourci + menu du Mac). **Une seule barre, en haut** (`InterfaceBar`) : à gauche le menu du projet (Réglages, Versions, Finder, Fermer — rien d'autre) et les panneaux de la page ; au centre les trois pages (`PageSwitch`) ; à droite **Partager**, Retours (Découpage), À vérifier, Détails. Plus de barre en bas, plus de bouton « ? » (menu Aide, ⌘/). Un panneau s'ouvre et se ferme seulement depuis la barre du haut (pas de croix). **Tout ce qui sort passe par Partager** (`ui/ShareDialog.tsx`, `state.share` : Publier sur le drive ⇧⌘P, Fichier ⌘E, Animatique, Retours reçus) ; les parties sont `PublishPane`, `ExportPane`, `AnimaticPane`, `RetoursPane` (`useShareBusy` empêche de fermer pendant un travail). Créer se fait sur la surface ; les actions d'un objet sont en pied de ses Détails, Supprimer en dernier ; deux styles d'action (bouton ; lien bleu pour aller ailleurs). Tests : `e2e/ui.ts` (`openSettings`, `share`).
